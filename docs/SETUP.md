# 安装和首次使用

v0.3.0 的公开安装包适用于 Apple Silicon Mac（arm64），最低部署目标为 macOS 14.0。实机验收范围见发行说明。[v0.3.0 发行页](https://github.com/mxk021/ResearchCompanion/releases/tag/v0.3.0)

## 下载与首次打开

1. 从发行页的 **Assets** 下载 `ResearchCompanion-0.3.0-arm64.dmg` 和 `ResearchCompanion-0.3.0-arm64.dmg.sha256`。在两者所在的目录运行 `shasum -a 256 -c ResearchCompanion-0.3.0-arm64.dmg.sha256`，确认输出为 `OK`。如果摘要不符，请丢弃该副本，从同一发行页重新下载。[v0.3.0 发行页](https://github.com/mxk021/ResearchCompanion/releases/tag/v0.3.0)
2. 打开 DMG，把 **Research Companion** 拖进「应用程序」。从「应用程序」双击打开。升级时，先退出正在运行的科研助手，再在同一位置替换应用，打开后通过菜单 **关于科研助手** 核对版本。
3. 公开包采用 ad hoc 签名，未经 Apple 公证。若 macOS 提示无法验证开发者，请先核实下载来源和摘要。仅在你信任来源且摘要一致时，尝试打开应用，再进入 **系统设置 → 隐私与安全性**，对本次拦截点「仍要打开」，按系统提示确认。如果系统提示 App 已损坏或会损坏电脑，请停止安装。受组织管理的 Mac 可能需要联系管理员。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

## 连接本机的 DSH

1. 安装官方 **DeepSeek Harness Desktop 0.2.2-rc.5**（应用标识 `com.deepseek.dsh`）。首次打开后等主窗口初始化，从 DSH 应用菜单正常退出。该精确版本及官方签名是随包安装科研桥的校验条件。若下载站已换成不同版本，请先核对现有安装。[DSH 官方下载](https://www.deepseek.com/harness/)
2. 打开科研助手，点聊天面板底部的 **连接设置 → 安装科研桥**。科研助手用 DSH 自带 CLI 将随包的 0.2.6 版科研桥离线加入当前用户的 `desktop` profile。请在操作结束前保持 DSH 退出。从 v0.2.11 或 v0.2.10 升级时，若此前由公开 App 安装原版科研桥，可用 **更新科研桥**。自定义桥接、修改过的插件及其他 profile 请沿用原维护方式。
3. 点 **打开 DSH**，保持 DSH 运行，回到科研助手等待连接。科研桥会自动注册专用工作区。新安装的位置为 `~/Library/Application Support/Research Companion/Workspace`。已有版本继续使用原来注册的科研工作区。
4. 在 DSH 中配置自己的模型账户。在科研助手聊天面板上方点 **选择模型** 或当前模型名，刷新目录并选择。DeepSeek 账户模型可能按余额计费。ChatGPT 订阅需要用户已有兼容的独立 DSH 提供方并完成授权。目录会说明未接入、尚未登录或无可用模型的状态。[模型与数据说明](#连接及数据)

## 阅读和导出笔记

1. 点 **选择文件**，关联 PDF、纯文本或 Markdown。PDF 材料卡显示已取得的标题、作者、网址或 DOI 及读取状态，扫描页可从材料卡的 **… → 本机 OCR 识别缺字页** 继续处理。
2. 等待索引就绪后提问。可用页码、栏号、章节、图表公式编号，或写「翻译从『起点原文』到『终点原文』的全部内容」。位置不唯一或两端之间存在不可读页时，面板会指出缺口。长范围分段任务可按界面显示的范围、模型和请求数确认。
3. 用 **选取文字** 或原应用的 **服务 → 选取文字（科研助手）** 取得选区。核对预览后可在输入框要求翻译或解释。重新取词失败时，可选择 **使用上次选区**。系统服务只交付正文，出处无法核对时会注明。没有可用选区时，仍可提问已关联的文件。
4. 在回答中点 **打开原文**，核对原文件版本、页位和高亮标注。回答用了多个位置时，可点 **上一处** 或 **下一处**。复杂版式可能造成图注边界、公式或阅读顺序识别不完整，遇到「待核对」提示时可在原页确认。使用了背景论文时，也可从 **来源 → 打开背景文件原文** 查看。
5. 点回答旁的 **保存为笔记**，或在其菜单选择 **另存为…**。Markdown 保存回答、所选公式和可核对的文字摘录。原页裁图保留在会话来源中供查看。

## 可选的系统权限和 Zotero

通过 **设置 → 交互与提醒 → 选取文字** 查看辅助功能授权。直接读其他应用选区需在 macOS 的 **系统设置 → 隐私与安全性 → 辅助功能** 允许「应用程序」内的科研助手。升级公开包后若权限不足，可只移除旧科研助手项，重新添加已安装的副本，再退出并重开它。

Safari 内嵌 PDF 优先使用系统文字服务。需要回退到原生复制时，科研助手会检查剪贴板格式是否可恢复，再尝试读取已核对的窗口。若格式无法安全恢复，可在原应用使用 **服务 → 选取文字（科研助手）**。Safari 有时会短暂获得焦点，取词期间普通聊天窗口继续可见。

WPS 直接读取失败时，科研助手可使用原生菜单复制。这个动作可能替换或清空通用剪贴板，取得的文字会标明出处未核验。部分阅读控件可按提示在原窗口按 ⌘C，再点 **粘贴选区**。文件问答可独立使用。

Zotero 10 的选区扩展可从 DMG 取出 `research-companion-context-0.1.6.xpi`，然后在 Zotero 的 **工具 → 插件 → 齿轮 → 从文件安装插件** 选择该文件。首次运行会生成仅限本机的配对密钥，同标识升级沿用已有密钥。在 Zotero 主窗口的阅读器标签页选中文字，然后点科研助手的 **选取文字**。带文件页的来源可回到 Zotero 对应页，无法核实页位时打开对应附件。支持范围为主窗口的阅读器标签页。[Zotero 下载](https://www.zotero.org/download/)

## 连接及数据

- **找不到 DSH**。核对下载来源、应用名及版本。科研助手验证兼容的官方签名后才会执行 DSH 随包的插件管理命令。
- **桥已登记，仍未连接**。打开 DSH，在插件列表确认 `dsh-research-companion` 加载成功。若安装中断，先查看 DSH 的插件诊断。应用将科研桥离线包存入 `~/.dsh/local-plugins/ResearchCompanion/`，请在 DSH 的 `file:` 依赖存续期间保留此目录。若 profile 已有第三方依赖且离线缓存不完整，请先修复原 profile。
- **模型目录及额度**。提供方维护模型列表、推理档和费用。科研助手使用 DSH 当前用户的授权。问答和模型协助检索会将本轮所需的聊天上下文、选区、摘录或原页裁图交给所选提供方，并在本机 DSH 会话中保存历史。公开包的模型账户和兼容提供方由用户自行配置。请从提交给 GitHub 的问题复现中移除 profile、配对文件、文献和凭据。
- **会话和笔记**。标准 DSH 可使用历史、检索及归档。永久删除仅在宿主明确具备相应维护能力时提供。公开包安装标准科研桥。已导出的 Markdown 独立保存在用户选定的目录。
- **移除桥接**。先从 DSH 菜单正常退出，再在终端执行下列 DSH 自带命令。原有会话、论文和笔记可在原位置保留。

```sh
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop remove dsh-research-companion
```
